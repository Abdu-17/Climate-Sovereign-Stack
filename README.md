# Climate-Sovereign Data Stack
### Research: The Sovereign Tipping Point & Macro-Financial Trilemma

This repository contains the technical implementation of the PhD proposal focused on EMDE climate resilience.

## Core Methodologies:
* **Double Machine Learning (DML)**: Causal inference for inflation-targeting regimes.
* **NASA-Bartik IV**: 0.5° x 0.625° grid-level identification using MERRA-2 satellite data.
* **TANK-DSGE Modeling**: Solving non-linear policy functions via Deep Reinforcement Learning (DRL).

## Technical Stack:
- Python (`xarray`, `dask`, `PyTorch`)
- Geospatial Engineering (NetCDF4 processing)
